CITYGUY FOOTBALL ANALYTICS — PROFESSIONAL WEBSITE STARTER

Included:
- index.html: responsive, mobile-friendly analytics dashboard starter.
- This is a static front-end demo. All example fixtures, scores and probabilities are fictional.

PUBLISH FREE WITH GITHUB PAGES:
1. Sign in or create a GitHub account.
2. Create a repository named cityguy-football (public repository for the free Pages option).
3. Upload index.html to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish and use the address shown there.
